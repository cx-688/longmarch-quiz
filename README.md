# 长征胜利 90 周年 · 知识竞赛答题

中国工农红军长征胜利 90 周年知识题库（170 道单选 + 70 道判断，共 240 题）做成的网页答题程序。
纯静态单文件，双击 `index.html` 即可使用，也可直接部署到任意静态托管（GitHub Pages / 校园服务器 / 网盘直链）。

## 功能

- **练习模式**：选择后立即判对错并给出正确答案，答完统计正确率、列出错题。
- **模拟考试**：按单选:判断 = 170:70 的比例随机抽题（20 / 40 / 70 / 全部），限时 15 或 30 分钟（可不限时），交卷后统一判分，列错题、记历史最高分。
- **题库浏览**：背题用，按原题库题号顺序显示题干、选项与正确答案。
- **答题卡**：随时跳题，已答/答对/答错不同颜色标识。
- 手机适配：竖屏单列布局，底部固定操作条，深色长征红主题。

## 目录

```
index.html          构建产物（自包含，题库已内联，可直接部署/双击）
build.py            构建脚本：把 src/ 里的题库与模板合成单文件
src/questions.json  从原始题库 .doc 解析出的结构化题目
src/template.html   页面模板（含样式与全部交互逻辑），题库位置为 /*__DATA__*/ 占位
```

构建产物只有 `index.html` 一份，不再保留副本目录。

## 重新构建

```bash
python build.py
```

## 数据说明

- 题目原文来自题库文件，未改写题干、未增删选项。
- 判断题第 70 题在原始文件中 `【答案】` 后为空，程序默认将该题排除（页面底部有提示）。补上答案后重新构建即可纳入。
- 题库 JSON 结构：`{ "single": [{id, stem, options:[{key,text}], answer}], "judge": [{id, stem, answer: true|false}] }`
